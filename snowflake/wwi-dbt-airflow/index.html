Snowflake Data Platform with dbt and Airflow

You will take WideWorldImporters, Microsoft's sample wholesale database on SQL Server, and build a complete analytics platform on Snowflake: a raw Bronze layer loaded incrementally, a Silver layer and Gold star schemas built with dbt, a Sales data mart for reporting, tests and a reconciliation that proves every number, all run by one simple Airflow DAG.

For: data engineers, analytics engineers, BI developers Prerequisite: SQL; some Python and Docker help 14 chapters + appendix
