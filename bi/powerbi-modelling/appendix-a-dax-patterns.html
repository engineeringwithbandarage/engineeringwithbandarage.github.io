DAX Pattern Cheat Sheet

Every pattern from the tutorial on one page, with the chapter that explains it. Names follow the AdventureWorksPL model: Sales, Date (with the 4-4-5 fiscal columns), Sales Territory, Channel, Currency and the _Measures table.

Measure layers (Chapter 5)

_Measures         = ROW ( "Placeholder", BLANK () )            -- calculated table, hide the column

_Gross Sales Base = SUM ( Sales[GrossSales] )                   -- 1 · base: one column, hidden
01 - Gross Sales  = [_Local Gross Sales]                        -- 2 · line: shared rules
03 - Net Sales    = [01 - Gross Sales] - [02 - Discounts]       -- 3 · derived: lines only
Gross Margin %    = DIVIDE ( [05 - Gross Profit], [03 - Net Sales] )   -- 4 · analysis

Last year on a fiscal calendar (Chapter 4)

03 - Net Sales LY =
CALCULATE (
    [03 - Net Sales],
    REMOVEFILTERS ( 'Date' ),
    TREATAS ( VALUES ( 'Date'[LYFiscalWeekID] ), 'Date'[FiscalWeekID] )
)

03 - Net Sales vs LY   = [03 - Net Sales] - [03 - Net Sales LY]
03 - Net Sales vs LY % = DIVIDE ( [03 - Net Sales vs LY], [03 - Net Sales LY] )

Calculation group for comparisons (Chapter 4)

-- Time Comparison[Comparison] items
Actual  : SELECTEDMEASURE ()
LY      : CALCULATE ( SELECTEDMEASURE (), REMOVEFILTERS ( 'Date' ),
                      TREATAS ( VALUES ( 'Date'[LYFiscalWeekID] ), 'Date'[FiscalWeekID] ) )
vs LY   : SELECTEDMEASURE () - CALCULATE ( SELECTEDMEASURE (), 'Time Comparison'[Comparison] = "LY" )
vs LY % : DIVIDE ( SELECTEDMEASURE () - CALCULATE ( SELECTEDMEASURE (), 'Time Comparison'[Comparison] = "LY" ),
                   CALCULATE ( SELECTEDMEASURE (), 'Time Comparison'[Comparison] = "LY" ) )   -- format "0.0%"

Period to date with a selector (Chapter 4)

Period To Date = DATATABLE ( "Period", STRING, "Sort", INTEGER,
                   { { "Week", 1 }, { "Period", 2 }, { "Quarter", 3 }, { "Year", 4 } } )

03 - Net Sales PTD =
VAR pick    = SELECTEDVALUE ( 'Period To Date'[Period], "Week" )
VAR lastDay = MAX ( 'Date'[Date] )
RETURN
    SWITCH ( pick,
        "Week",    CALCULATE ( [03 - Net Sales], REMOVEFILTERS ( 'Date' ), 'Date'[FiscalWeekID] = MAX ( 'Date'[FiscalWeekID] ) ),
        "Period",  CALCULATE ( [03 - Net Sales], REMOVEFILTERS ( 'Date' ), 'Date'[FiscalPeriodID] = MAX ( 'Date'[FiscalPeriodID] ), 'Date'[Date] <= lastDay ),
        "Quarter", CALCULATE ( [03 - Net Sales], REMOVEFILTERS ( 'Date' ), 'Date'[FiscalQuarterID] = MAX ( 'Date'[FiscalQuarterID] ), 'Date'[Date] <= lastDay ),
        "Year",    CALCULATE ( [03 - Net Sales], REMOVEFILTERS ( 'Date' ), 'Date'[FiscalYear] = MAX ( 'Date'[FiscalYear] ), 'Date'[Date] <= lastDay ) )

MAX inside a CALCULATE filter

In a filter argument like 'Date'[FiscalWeekID] = MAX ( 'Date'[FiscalWeekID] ), the MAX is evaluated in the outer filter context, before REMOVEFILTERS applies, so it returns the last week of the user's selection. Chapter 4 stores these values in variables, which says the same thing more explicitly.

Local-currency conversion (Chapter 6)

_Show Local Currency =
HASONEVALUE ( 'Currency'[CurrencyKey] ) && NOT SELECTEDVALUE ( 'Currency'[IsReportingCurrency] )

_Local Gross Sales =
IF ( [_Show Local Currency],
     SUMX ( Sales, Sales[GrossSales] * Sales[LocalCurrencyRate] ),
     [_Gross Sales Base] )
