Chapter 02 · Beginner

Installing uv and First Commands

uv is a single executable with no dependencies, not even Python. In this chapter you install it, confirm it works, learn where it keeps its files, and run Python code through it for the first time.

~15 min Windows · macOS · Linux You need: a terminal and an internet connection

Step 1: Install uv

The recommended way is Astral's standalone installer. It downloads the right binary for your machine, puts it in your user folder (no admin rights needed) and adds that folder to your PATH.

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
$ curl -LsSf https://astral.sh/uv/install.sh | sh
# no curl? use wget instead
$ wget -qO- https://astral.sh/uv/install.sh | sh

Prefer your package manager? These work too:

Piping a script into a shell

curl … | sh runs a script from the internet. That's normal for developer tools, but if your organisation doesn't allow it, download the script first and read it, or use WinGet, Homebrew or pip instead. They all install the same uv.

Step 2: Check it works

Open a new terminal (so it picks up the updated PATH) and run:

$ uv --version
uv X.Y.Z (…)

$ uvx --version
uvx X.Y.Z (…)

Your version number will be different, and that's fine. Two commands were installed: uv itself and uvx, a shortcut for running tools that you'll meet in Chapter 8.

"uv is not recognized" or "command not found"?

The terminal was opened before the install changed PATH. Close it and open a new one. If that doesn't help, check that the folder the installer printed (usually ~/.local/bin, or %USERPROFILE%\.local\bin on Windows) is on your PATH.

Step 3: Get to know the help

uv's help is good and always matches your installed version. Use it whenever this tutorial and your version disagree.

$ uv                    # list of all commands
$ uv help run           # full help for one command
$ uv run --help         # shorter help for one command

Step 4: Your first commands

Let's run Python through uv. You don't need Python installed first: if uv can't find a suitable interpreter, it downloads one automatically.

$ uv run python -c "import sys; print(sys.version)"
3.13.x (main, …) [Clang …]

Now run something that needs a package from PyPI, without installing anything permanently:

$ uv run --with rich python -c "from rich import print; print('[bold green]Hello from uv![/]')"
Installed 4 packages in 12ms
Hello from uv!

uv created a temporary environment, installed rich and its dependencies into it, ran the command and left your system untouched. Run the same line again: it's even faster, because the packages are now in uv's cache.

And a command-line tool, also without installing it:

$ uvx pycowsay "uv is installed"

Where uv keeps its files

uv stores everything in four places inside your user profile. Knowing them makes troubleshooting and clean-up easy.

WhatLinux and macOSWindowsAsk uv
Executables~/.local/bin%USERPROFILE%\.local\binuv tool dir --bin
Cache~/.cache/uv%LOCALAPPDATA%\uv\cacheuv cache dir
Managed Pythons~/.local/share/uv/python%APPDATA%\uv\pythonuv python dir
Tool environments~/.local/share/uv/tools%APPDATA%\uv\toolsuv tool dir

Always prefer the "Ask uv" column: environment variables such as UV_CACHE_DIR can move any of these.

Step 5: Keep uv up to date

$ uv self update                 # standalone installer only
$ uv self update X.Y.Z           # or move to a specific version, e.g. the one your CI uses

If you installed with WinGet, Homebrew, pipx or pip, update with that tool instead (see the table in Step 1). uv self update refuses to touch an install it didn't make.

Optional: shell completion

Tab-completion for commands and options saves a lot of typing. Add one line to your shell's start-up file:

eval "$(uv generate-shell-completion bash)"     # bash
eval "$(uv generate-shell-completion zsh)"      # zsh
eval "$(uvx --generate-shell-completion bash)"  # completion for uvx too
(& uv generate-shell-completion powershell) | Out-String | Invoke-Expression

Uninstalling (for reference)

If you ever need to remove uv completely, clean its data first, then delete the binaries:

$ uv cache clean
$ rm -r "$(uv python dir)" "$(uv tool dir)"
$ rm ~/.local/bin/uv ~/.local/bin/uvx

Key takeaways

  • Install uv with the standalone installer, WinGet, Homebrew or pip. It doesn't need Python and doesn't need admin rights.
  • Open a new terminal after installing, then check with uv --version.
  • uv run --with <package> and uvx <tool> run code in throw-away environments without changing your system.
  • uv keeps executables, a cache, managed Pythons and tool environments in your user profile. Find them with uv cache dir, uv python dir and uv tool dir.
