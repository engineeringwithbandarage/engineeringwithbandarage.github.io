uv Hands-On: From First Script to Production

uv is a single program, written in Rust by Astral, that installs Python, creates virtual environments, resolves and locks dependencies, runs scripts and tools, and builds and publishes packages. It replaces pip, pip-tools, virtualenv, pyenv, pipx and most of Poetry, and it is usually 10 to 100 times faster than them. This tutorial starts from zero and ends with production Docker images and CI pipelines.

For: anyone who writes Python, from first-timers to platform engineers Prerequisite: a terminal and basic Python Windows, macOS and Linux

How the tutorial is built

  • Three levels. Beginner (chapters 1–4) needs no packaging knowledge at all. Intermediate (5–9) is what you use every day on real projects. Advanced (10–12) covers monorepos, publishing, containers, CI and how uv works inside.
  • Type along. Every chapter is a sequence of commands you run yourself, with the output you should see. The running example is fuelprice, a small command-line app that grows from a single script into a tested, packaged, containerised project.
  • Diagrams for the ideas that matter. Where uv keeps things, how a command decides what to do, and which file is the source of truth: each is drawn once, in the chapter that needs it.

Versions

uv is released often. The commands in this tutorial are stable, but newer releases add options. Run uv --version and check uv help <command> when an option behaves differently from what you see here.
