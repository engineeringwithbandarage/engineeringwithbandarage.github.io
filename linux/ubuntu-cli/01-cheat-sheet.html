Cheat sheet · Ubuntu 22.04 and 24.04 LTS

The Ubuntu Command-Line Cheat Sheet

The commands an Ubuntu administrator reaches for every day, grouped by task. Each one has a short explanation, and the button beside it copies the command. Words in angle brackets, such as <file>, are placeholders: replace them, brackets included. Use the contents list or your browser's find (Ctrl+F) to jump to what you need.

Ubuntu Server and Desktop Bash Copy any command with one click

sudo means "as administrator"

Commands that start with sudo change the system and ask for your password. Read them before running them, especially anything that deletes, stops a service or changes the firewall on a remote server.

System information

CommandWhat it does
uname -aKernel name, version and architecture.
cat /etc/os-releaseUbuntu release and version, for example 24.04 LTS.
hostnamectlHostname, operating system, kernel and hardware model. sudo hostnamectl set-hostname <name> changes the hostname.
uptimeHow long the machine has been running, and the load averages.
lscpuCPU architecture, cores and threads.
lsblkDisks and partitions as a tree, with sizes and mount points.
timedatectlCurrent time, time zone and whether the clock is synchronised. sudo timedatectl set-timezone Asia/Colombo sets the zone.

Monitoring and processes

CommandWhat it does
topLive view of processes, CPU and memory. Press q to quit.
htopA friendlier, colour top. Install it first with sudo apt install htop.
free -hUsed and available memory in human-readable units. Look at the "available" column, not "free".
df -hFree space on each mounted file system.
du -sh <directory>Total size of a directory. du -sh * | sort -h ranks the items in the current one.
ps auxEvery running process with its owner, CPU and memory use.
pgrep -a <name>Find processes by name and show their process IDs (PIDs).
kill <pid>Ask a process to stop cleanly (signal SIGTERM).
kill -9 <pid>Force a process to stop (SIGKILL). A last resort: the process cannot clean up.
pkill <name>Stop processes by name instead of PID.

Background jobs in the shell

CommandWhat it does
<command> &Run a command in the background.
jobsList background jobs in this shell, numbered 1, 2, …
fg %1Bring job 1 back to the foreground. Pressing Ctrl+Z pauses the foreground job; bg %1 resumes it in the background.
nohup <command> &Keep a command running after you log out. Output goes to nohup.out.

Services and logs (systemd)

CommandWhat it does
systemctl status <service>Whether a service is running, with its most recent log lines.
sudo systemctl start <service>Start a service now.
sudo systemctl stop <service>Stop a service now.
sudo systemctl restart <service>Stop and start again.
sudo systemctl reload <service>Re-read the configuration without stopping, for services that support it (for example nginx).
sudo systemctl enable --now <service>Start at every boot, and start it now as well. disable does the opposite.
systemctl list-units --type=service --state=runningAll running services.
systemctl --failedUnits that failed to start: the first thing to check after a problem.
journalctl -u <service>Logs of one service. Add -f to follow new lines live.
journalctl -b -p errErrors since the last boot.
journalctl --since "1 hour ago"Everything logged in the last hour.

Scheduled jobs (cron)

CommandWhat it does
crontab -eEdit your scheduled jobs. sudo crontab -e edits root's.
crontab -lList your scheduled jobs.
systemctl list-timersJobs scheduled with systemd timers, the modern alternative to cron.

Each crontab line has five time fields, then the command: minute, hour, day of month, month, day of week.

# m  h  dom mon dow  command
30   2  *   *   *    /usr/local/bin/backup.sh          # every day at 02:30
*/15 *  *   *   *    /usr/local/bin/check-disk.sh      # every 15 minutes
0    9  *   *   1-5  /usr/local/bin/report.sh          # 09:00, Monday to Friday

Files and directories

CommandWhat it does
pwdShow the directory you are in.
ls -lahList files in detail: permissions, owner, size, date, including hidden files.
cd <directory>Change directory. cd ~ goes home, cd - goes back to the previous one.
mkdir -p <path>Create a directory, including any missing parent directories.
touch <file>Create an empty file, or update an existing file's timestamp.
cp <source> <destination>Copy a file. Add -r to copy a directory and everything in it.
mv <source> <destination>Move or rename a file or directory.
rm <file>Delete a file. There is no recycle bin.
rm -r <directory>Delete a directory and everything in it. Double-check the path first.
ln -s <target> <link>Create a symbolic link (shortcut) to a file or directory.

Permissions and ownership

Every file has an owner, a group, and three sets of permissions: for the user (owner), the group and others. Each set is a combination of read (4), write (2) and execute (1). So 755 means rwx for the owner and r-x for everyone else.

CommandWhat it does
chmod 644 <file>Owner can read and write; everyone else can only read. Typical for files.
chmod 755 <dir-or-script>Owner can do everything; others can read and enter or run. Typical for directories and scripts.
chmod u+x <file>Make a file executable by its owner.
sudo chown <user>:<group> <file>Change a file's owner and group. Add -R to apply it to a whole directory.

Searching

CommandWhat it does
find <directory> -name "*.log"Find files by name. Quote the pattern so the shell does not expand it.
find /var -size +100MFind files larger than 100 MB: useful when a disk fills up.
find <directory> -mtime -1Files modified in the last 24 hours.
grep "<text>" <file>Show lines containing the text. -i ignores case, -n shows line numbers.
grep -rn "<text>" <directory>Search every file under a directory.

Archives and compression

CommandWhat it does
tar -czvf <name.tar.gz> <files>Create a gzip-compressed archive, verbosely, into the file named.
tar -xvf <archive>Extract an archive into the current directory. Works for .tar.gz, .tar.bz2 and .tar.xz alike.
tar -xvf <archive> -C <directory>Extract into another directory, which must already exist.
tar -tvf <archive>List an archive's contents without extracting.
unzip <file.zip>Extract a zip file. Install with sudo apt install unzip if missing.

Viewing and editing text

CommandWhat it does
nano <file>A simple editor. Ctrl+O saves, Ctrl+X exits.
cat <file>Print a whole file.
less <file>Page through a file. / searches, q quits.
head -n 20 <file>The first 20 lines.
tail -n 50 <file>The last 50 lines. tail -f keeps showing new lines as they are written: ideal for logs.
wc -l <file>Count lines.
sort <file> | uniq -cCount how often each line occurs.
awk '{print $1}' <file>Print the first column of each line.
sed -i 's/old/new/g' <file>Replace text throughout a file, in place. Try it without -i first to preview.
diff <file1> <file2>Show the differences between two files.

Packages with APT

CommandWhat it does
sudo apt updateRefresh the list of available packages. Run it before installing or upgrading.
sudo apt upgradeUpgrade all installed packages. sudo apt full-upgrade also allows adding or removing packages when upgrades need it.
sudo apt install <package>Install a package and its dependencies.
sudo apt remove <package>Uninstall a package but keep its configuration files.
sudo apt purge <package>Uninstall a package and delete its configuration files.
sudo apt autoremoveRemove dependencies nothing needs any more.
apt search <keyword>Search the available packages.
apt show <package>Describe a package: version, size, dependencies.
apt list --installedEverything installed.
apt-cache policy <package>Installed version, candidate version and which repository each comes from.
sudo apt install --reinstall <package>Reinstall a package whose files were damaged.
sudo apt --fix-broken installRepair broken or missing dependencies, for example after an interrupted install.

Packages with Snap

CommandWhat it does
snap find <keyword>Search the Snap Store.
sudo snap install <snap>Install a snap. Some need --classic for full system access.
snap listInstalled snaps with versions and channels.
snap info <snap>Description, publisher and available channels.
sudo snap refreshUpdate all snaps now (they also update automatically).
sudo snap revert <snap>Go back to the previous version after a bad update.
sudo snap remove <snap>Uninstall a snap.

Networking

CommandWhat it does
ip -br addrEach network interface with its state and IP addresses, one line each.
ip routeThe routing table, including the default gateway.
ip -s linkTraffic and error counters for each interface.
sudo ss -tulpnEvery listening TCP and UDP port, with the program using it.
ping -c 4 <host>Send four test packets and report the round-trip times.
resolvectl query <name>Look up a domain name with the system resolver.
curl -I <url>Fetch only the HTTP headers: a quick check that a web service answers.
tracepath <host>Show the route packets take to a host.

Network configuration with Netplan

Ubuntu stores network settings as YAML files in /etc/netplan/. Edit them, then test before applying.

CommandWhat it does
sudo cat /etc/netplan/*.yamlShow the current configuration.
sudo netplan tryApply a new configuration and roll it back automatically after 120 seconds unless you confirm it. Safest on a remote server.
sudo netplan applyApply the configuration permanently.
 
network:
  version: 2
  ethernets:
    enp0s3:                       # interface name from: ip -br addr
      dhcp4: false
      addresses: [192.168.1.50/24]
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses: [1.1.1.1, 8.8.8.8]

Firewall (UFW)

On a remote server, allow SSH before enabling the firewall

Enabling UFW blocks all incoming connections that are not allowed. Run sudo ufw allow OpenSSH first, or you will lock yourself out.

CommandWhat it does
sudo ufw status verboseWhether the firewall is on, its default policies and rules.
sudo ufw allow OpenSSHAllow SSH using its application profile (port 22).
sudo ufw enableTurn the firewall on, now and at every boot.
sudo ufw allow 443/tcpAllow a port and protocol.
sudo ufw allow from <ip> to any port 22Allow SSH only from one address.
sudo ufw deny <port>Block a port.
sudo ufw status numberedRules with numbers, then sudo ufw delete <number> removes one.
sudo ufw disableTurn the firewall off.

SSH and file transfer

CommandWhat it does
ssh <user>@<host>Log in to a remote machine. -p <port> if it does not use port 22.
ssh-keygen -t ed25519Create a key pair for password-less, more secure logins.
ssh-copy-id <user>@<host>Install your public key on a server so you can log in with the key.
scp <file> <user>@<host>:<path>Copy a file to a server. Swap the two arguments to copy back; add -r for directories.
rsync -avz <source> <user>@<host>:<path>Copy only what changed: faster and resumable for large or repeated transfers.

Users and groups

CommandWhat it does
whoamiYour user name.
wWho is logged in and what they are running.
id <user>A user's ID and every group they belong to.
sudo adduser <user>Create a user with a home directory, asking for a password.
sudo usermod -aG <group> <user>Add a user to a group, for example sudo. Keep the -a: without it the user is removed from all other groups. Takes effect at the next login.
sudo gpasswd -d <user> <group>Remove a user from a group.
sudo passwd <user>Set or change a user's password.
sudo passwd -l <user>Lock a user's password; -u unlocks it.
sudo chage -l <user>Show password ageing and account expiry. sudo chage -E 2026-12-31 <user> sets the account to expire on that date.
su - <user>Switch to another user with their full environment.
sudo deluser --remove-home <user>Delete a user and their home directory.
sudo addgroup <group>Create a group; sudo delgroup <group> deletes one.

Containers and VMs with LXD

LXD runs lightweight system containers and virtual machines, each a full Ubuntu (or other Linux) you can log in to.

CommandWhat it does
sudo snap install lxdInstall LXD, if it is not already installed.
sudo usermod -aG lxd $USERLet your user run LXD without sudo. Log out and back in afterwards.
lxd init --minimalSet LXD up with default storage and networking. Run lxd init to answer the questions yourself.
lxc launch ubuntu:24.04 <name>Create and start a container.
lxc launch ubuntu:24.04 <name> --vmCreate and start a virtual machine instead.
lxc listAll instances with their state and IP addresses.
lxc exec <name> -- bashOpen a shell inside an instance. Replace bash with any command to run just that.
lxc stop <name>Stop an instance; lxc start <name> starts it again.
lxc snapshot <name> <snapshot>Save the instance's current state; lxc restore <name> <snapshot> returns to it.
lxc file push <local-file> <name>/<path>Copy a file into an instance; lxc file pull copies one out.
lxc delete <name> --forceDelete an instance, stopping it first if needed.

Ubuntu Pro

Ubuntu Pro is Canonical's subscription that extends security updates for LTS releases to ten years and adds services such as Livepatch. At the time of writing it is free for personal use on a small number of machines; see ubuntu.com/pro.

CommandWhat it does
sudo pro attach <token>Connect the machine to your Ubuntu Pro subscription, using the token from your Ubuntu Pro dashboard.
pro statusWhich services are available and enabled.
sudo pro enable esm-infraExtended security updates for the main Ubuntu packages.
sudo pro enable esm-appsExtended security updates for packages from the Universe repository.
sudo pro enable livepatchApply critical kernel security fixes without rebooting.
sudo pro disable <service>Turn a service off.
sudo pro detachDisconnect the machine from Ubuntu Pro.

FIPS mode is not a casual switch

sudo pro enable fips installs certified cryptographic modules and a different kernel for regulated environments. It needs a reboot and is hard to undo, so enable it only when compliance requires it.
