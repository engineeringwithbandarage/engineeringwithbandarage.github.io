Describing data

Sample mean

\bar{x} = \frac{\sum x_i}{n}

Population mean

\mu = \frac{\sum x_i}{N}

Sample variance / SD

s^2 = \frac{\sum (x_i - \bar{x})^2}{n - 1}, \quad s = \sqrt{s^2}

Shortcut: s^2 = \dfrac{\sum x^2 - (\sum x)^2/n}{n - 1}

Population SD

\sigma = \sqrt{\frac{\sum (x_i - \mu)^2}{N}}

Range, IQR

\max - \min, \qquad Q_3 - Q_1

Fences (outliers)

Q_1 - 1.5\,\text{IQR}, \qquad Q_3 + 1.5\,\text{IQR}

z-score

z = \frac{x - \bar{x}}{s} \quad \text{or} \quad z = \frac{x - \mu}{\sigma}

Chebyshev's rule

P(|x - \mu| < k\sigma) \ge 1 - \frac{1}{k^2}

Empirical rule (bell-shaped)

\mu \pm \sigma,\ 2\sigma,\ 3\sigma:\ 68\%,\ 95\%,\ 99.7\%

Probability

Equal likelihood

P(E) = \frac{f}{N}

Complement

P(\text{not } E) = 1 - P(E)

General addition

P(A \text{ or } B) = P(A) + P(B) - P(A \mathbin{\&} B)

Mutually exclusive: P(A \text{ or } B) = P(A) + P(B)

Conditional

P(B \mid A) = \frac{P(A \mathbin{\&} B)}{P(A)}

General multiplication

P(A \mathbin{\&} B) = P(A)\,P(B \mid A)

Independent: P(A \mathbin{\&} B) = P(A)\,P(B)

Total probability

P(B) = \sum_j P(A_j)\,P(B \mid A_j)

Bayes' rule

P(A_i \mid B) = \frac{P(A_i)\,P(B \mid A_i)}{\sum_j P(A_j)\,P(B \mid A_j)}

Counting

{}_mP_r = \frac{m!}{(m - r)!}, \qquad {}_mC_r = \frac{m!}{r!\,(m - r)!}

Random variables & distributions

Discrete mean / variance

\mu = \sum x\,P(x), \quad \sigma^2 = \sum (x - \mu)^2 P(x)

Binomial

P(x) = \binom{n}{x} p^x (1 - p)^{n - x}

\mu = np, \quad \sigma = \sqrt{np(1 - p)}

Poisson

P(x) = e^{-\lambda} \frac{\lambda^x}{x!}

\mu = \lambda, \quad \sigma = \sqrt{\lambda}

Standardising a normal

z = \frac{x - \mu}{\sigma}, \qquad x = \mu + z\sigma

Normal approx. to binomial

np \ge 5,\ n(1 - p) \ge 5; \ \pm 0.5 \text{ correction}

Sampling distribution of x̄

\mu_{\bar{x}} = \mu, \qquad \sigma_{\bar{x}} = \frac{\sigma}{\sqrt{n}}

Multiply by \sqrt{\tfrac{N - n}{N - 1}} if n > 5 % of N

Confidence intervals

Mean, σ known

\bar{x} \pm z_{\alpha/2} \frac{\sigma}{\sqrt{n}}

Mean, σ unknown

\bar{x} \pm t_{\alpha/2} \frac{s}{\sqrt{n}}, \quad df = n - 1

Sample size for a mean

n = \left(\frac{z_{\alpha/2}\,\sigma}{E}\right)^2

Proportion

\hat{p} \pm z_{\alpha/2} \sqrt{\frac{\hat{p}(1 - \hat{p})}{n}}

Plus-four: \tilde{p} = \frac{x + 2}{n + 4}, use n + 4 in the SE

Sample size for a proportion

n = \hat{p}_g (1 - \hat{p}_g) \left(\frac{z_{\alpha/2}}{E}\right)^2

Worst case: n = 0.25\,(z_{\alpha/2}/E)^2

Standard deviation

\sqrt{\frac{(n - 1)s^2}{\chi^2_{\alpha/2}}} \ \text{to} \ \sqrt{\frac{(n - 1)s^2}{\chi^2_{1 - \alpha/2}}}

Two means, Welch

(\bar{x}_1 - \bar{x}_2) \pm t_{\alpha/2} \sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}

Two means, pooled

(\bar{x}_1 - \bar{x}_2) \pm t_{\alpha/2}\, s_p \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}

df = n_1 + n_2 - 2

Paired

\bar{d} \pm t_{\alpha/2} \frac{s_d}{\sqrt{n}}

Two proportions

(\hat{p}_1 - \hat{p}_2) \pm z_{\alpha/2} \sqrt{\frac{\hat{p}_1(1 - \hat{p}_1)}{n_1} + \frac{\hat{p}_2(1 - \hat{p}_2)}{n_2}}

Ratio of two SDs

\frac{s_1/s_2}{\sqrt{F_{\alpha/2}}} \ \text{to} \ \frac{s_1/s_2}{\sqrt{F_{1 - \alpha/2}}}

Test statistics

One mean

z = \frac{\bar{x} - \mu_0}{\sigma/\sqrt{n}}, \qquad t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}

One proportion

z = \frac{\hat{p} - p_0}{\sqrt{p_0(1 - p_0)/n}}

One SD

\chi^2 = \frac{(n - 1)s^2}{\sigma_0^2}, \quad df = n - 1

Two means, Welch

t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{s_1^2/n_1 + s_2^2/n_2}}

df = \dfrac{(s_1^2/n_1 + s_2^2/n_2)^2}{\frac{(s_1^2/n_1)^2}{n_1 - 1} + \frac{(s_2^2/n_2)^2}{n_2 - 1}}

Pooled SD

s_p = \sqrt{\frac{(n_1 - 1)s_1^2 + (n_2 - 1)s_2^2}{n_1 + n_2 - 2}}

Paired

t = \frac{\bar{d}}{s_d/\sqrt{n}}, \quad df = n - 1

Two proportions

z = \frac{\hat{p}_1 - \hat{p}_2}{\sqrt{\hat{p}_p(1 - \hat{p}_p)\left(\frac{1}{n_1} + \frac{1}{n_2}\right)}}

\hat{p}_p = (x_1 + x_2)/(n_1 + n_2)

Two SDs

F = \frac{s_1^2}{s_2^2}, \quad df = (n_1 - 1,\ n_2 - 1)

Wilcoxon signed-rank

W = \text{sum of the positive signed ranks}

Mann–Whitney

M = \text{sum of the ranks of sample 1}

Chi-square

Statistic

\chi^2 = \sum \frac{(O - E)^2}{E}

Goodness of fit

E = n\,p_i, \qquad df = k - 1

Independence / homogeneity

E = \frac{R \cdot C}{n}, \qquad df = (r - 1)(c - 1)

R, C = row and column totals

Cramér's V

V = \sqrt{\frac{\chi^2}{n\,(\min(r, c) - 1)}}

Regression & correlation

Sums

S_{xx} = \sum (x - \bar{x})^2, \ S_{xy} = \sum (x - \bar{x})(y - \bar{y})

S_{yy} = \sum (y - \bar{y})^2

Least squares

b_1 = \frac{S_{xy}}{S_{xx}}, \qquad b_0 = \bar{y} - b_1 \bar{x}

Sums of squares

SST = SSR + SSE, \quad SSR = \frac{S_{xy}^2}{S_{xx}}

R² and r

R^2 = \frac{SSR}{SST}, \qquad r = \frac{S_{xy}}{\sqrt{S_{xx} S_{yy}}}

Standard error of estimate

s_e = \sqrt{\frac{SSE}{n - 2}}

Slope test & CI

t = \frac{b_1}{s_e/\sqrt{S_{xx}}}, \quad b_1 \pm t_{\alpha/2} \frac{s_e}{\sqrt{S_{xx}}}

df = n - 2

CI for mean response

\hat{y} \pm t_{\alpha/2}\, s_e \sqrt{\frac{1}{n} + \frac{(x_0 - \bar{x})^2}{S_{xx}}}

Prediction interval

\hat{y} \pm t_{\alpha/2}\, s_e \sqrt{1 + \frac{1}{n} + \frac{(x_0 - \bar{x})^2}{S_{xx}}}

Correlation test

t = \frac{r\sqrt{n - 2}}{\sqrt{1 - r^2}}, \quad df = n - 2

ANOVA

Sums of squares

\begin{gathered} SSTR = \sum n_j (\bar{x}_j - \bar{x})^2 \\ SSE = \sum (n_j - 1)s_j^2 \end{gathered}

SST = SSTR + SSE

F

F = \frac{SSTR/(k - 1)}{SSE/(n - k)}

η²

\eta^2 = \frac{SSTR}{SST}

Kruskal–Wallis

H = \frac{12}{n(n + 1)} \sum \frac{R_j^2}{n_j} - 3(n + 1)

df = k - 1

Hero level

Effective sample size (AR(1))

n_{\text{eff}} \approx n \, \frac{1 - \rho_1}{1 + \rho_1}

Bonferroni

\text{reject if } p_i \le \frac{\alpha}{m}

Logistic model

\ln \frac{p}{1 - p} = b_0 + b_1 x_1 + \dots, \quad OR = e^{b}

Beta–binomial update

\text{Beta}(a, b) \to \text{Beta}(a + x,\ b + n - x)

Exponential decline

q = q_0 e^{-Dt} \iff \ln q = \ln q_0 - Dt
