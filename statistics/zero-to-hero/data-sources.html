Data, Code & Reproducibility

Every example in this course is a real analysis of an open dataset. This page lists the sources and licences, describes the database built from them, and shows how to rerun the whole pipeline.

Derived extracts used by the pages are JSON files in statistics/data/: results.json, spot_daily.json, ncs_wells.json, ncs_fields.json, ncs_production.json, refinery_util_weekly.json, crude_stocks_weekly.json, gasoline_crude_monthly.json, owid_countries.json, owid_top_producers.json and wb_monthly.json.

Pipeline

  1. Fetch the raw files with 01_fetch.sh and 05_fetch_padd.sh.
  2. Load them into PostgreSQL with etl.py (run by 03_etl.sh inside a Python container built from this Dockerfile). It also writes the JSON extracts.
  3. Create the helper views with 01_views.sql.
  4. Analyse with analysis.py (06_analysis.sh), which computes every quoted number into results.json.
  5. Check the SQL shown on the pages with 02_chapter_checks.sql.

The pages read results.json and fill numbers into the text, so rerunning the pipeline on fresh data updates the prose automatically. Interactive widgets recompute from the JSON extracts in your browser using the course's small statistics library.

Definitions used throughout

  • Wildcat: exploration wellbore with purpose "WILDCAT" (first test of a prospect). Appraisal wells are excluded from success rates.
  • Discovery: reported content oil, gas, oil/gas, gas/condensate or oil/gas/condensate. Dry, shows and water count as no discovery; wells with content "not applicable/available" are excluded.
  • Returns: log returns in percent, 100·ln(Pt/Pt−1); monthly returns use monthly average prices.
  • Field size: latest recoverable oil-equivalent estimate per field, million standard m³.
